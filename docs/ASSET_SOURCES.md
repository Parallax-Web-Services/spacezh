# Visual asset sources

## Ukrainian tryzub

- Local asset: `public/assets/tryzub.svg`.
- Source: [Coat of Arms of Ukraine.svg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Coat_of_Arms_of_Ukraine.svg), checked 17 October 2026. [Pinned description revision](https://commons.wikimedia.org/w/index.php?title=File:Coat_of_Arms_of_Ukraine.svg&oldid=1263033409).
- Published vector: Andrew Pertsev, 15 October 2022, based on the design attributed to Vasyl Krychevsky. The source records 660 × 922 dimensions and SHA-1 `f1b0e865226f56a152eaaf2568d8840a5385328e` for its 705-byte SVG.
- Reuse basis: Commons identifies the adopted Ukrainian state symbol as public domain under its PD-UA-exempt state-symbol notice. Insignia use remains separate from copyright; the site uses the emblem to express solidarity, without claiming governmental status or endorsement.
- Verification: both path definitions, fills, stroke and mirrored `use` match the source's published SVG code. The existing source geometry is retained; local additions provide a responsive viewBox, accessible title/description and source metadata. CSS removes the former drop shadow and gives the small emblem more space. The mirror transform belongs to the original vector geometry; no visual distortion, blur or rotation is applied.
